# SERA 1.0 — Navigation Model & Keyboard Shortcuts

## 1. Domain-Based Navigation Hierarchy

```
COMMAND
  [1] LIVE           — Conversational Stream & Reactive Aura Orb
  [2] WORKFLOW       — Horizontal Execution Graph & Candidate Editor

INTELLIGENCE
  [3] AGENTS         — Multi-Agent Hierarchy & Work Executors
  [4] MEMORY         — Neural Knowledge Core & Categorical Memory

SYSTEM
  [5] PROVIDERS      — Multi-Provider Dashboard & Dynamic Quotas
  [6] HISTORY        — Session History & Telemetry Traces
  [7] DEBUG          — Latency Waterfall & EventBus Log
  [8] SECURITY       — Permission Policies & Privacy Controls
```

## 2. Keyboard Navigation Shortcuts

| Key | Target View | Operational Domain | Description |
|---|---|---|---|
| `1` | `LIVE` | COMMAND | Main conversational view and voice orb |
| `2` | `WORKFLOW` | COMMAND | Temporal execution graph and role candidate editor |
| `3` | `AGENTS` | INTELLIGENCE | Multi-agent hierarchy |
| `4` | `MEMORY` | INTELLIGENCE | Categorical neural memory and search |
| `5` | `PROVIDERS` | SYSTEM | Model providers, health, and dynamic quotas |
| `6` | `HISTORY` | SYSTEM | Chronological interaction sessions |
| `7` | `DEBUG` | SYSTEM | Latency waterfall and live EventBus stream |
| `8` | `SECURITY` | SYSTEM | SecurityManager rules and privacy matrix |
| `Ctrl + Space` | *Global* | SYSTEM | Activate SERA Voice Capture (5-second window) |
| `Esc` | *Global* | SYSTEM | Close sliding inspector drawer or modal dialog |
